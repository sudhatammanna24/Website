# Sudha T — DevOps Engineer (portfolio)

Static résumé website. No build step, no dependencies.

## Publish on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io` (or any name, e.g. `resume`).
2. Upload `index.html` and `Sudha_T_DevOps_Resume.docx` to the repo root.
3. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. Your site goes live at `https://<your-github-username>.github.io/` (or `/resume/` for a differently named repo) in about a minute.
